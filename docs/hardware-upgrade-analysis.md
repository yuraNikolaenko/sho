# Аналіз апгрейду RAM для AI-функцій Shozilla

Документ з аналізом можливості та доцільності апгрейду пам'яті ноутбука для запуску локальних LLM (див. AI-1, AI-2 у [TODO.md](../TODO.md)).

> **Статус**: рішення відкладено. Початково працюємо з Qwen 1.5B на поточному залізі. Питання апгрейду повертати **тільки** якщо якість 1.5B виявиться недостатньою на реальних документах і будуть на руках перевірені роздрібні ціни в Україні.

## Поточна конфігурація (зчитано з BIOS)

| Параметр | Значення |
|---|---|
| Ноутбук | HP Laptop 14s-fq0xxx |
| Серійний номер | 5CD1047F0C |
| BIOS | AMI F.52 (22.09.2021) |
| CPU | AMD Ryzen 3 3250U (Zen+, 2 ядра / 4 потоки, 2.6 GHz) |
| Інтегрована GPU | AMD Radeon Vega (UMA, 2 GB виділено з системної RAM) |
| RAM встановлено | 1× Hynix HMA81GS6DJR8N-XN, 8 GB DDR4-3200 SO-DIMM |
| Слот зайнятий | "Bottom - Slot 1 (left)" (лівий, доступ знизу) |
| Слотів усього | **2** (другий пустий) |
| Робоча швидкість | 2400 MT/s (CPU обмежує DDR4-3200 до 2400) |
| Максимум по BIOS | 32 GB (2× 16 GB) |
| Видно Windows | ~5.88 GB (8 GB мінус 2 GB UMA для iGPU) |

## Ключові висновки про апгрейдність

1. **Нічого не припаяно до материнки.** Уся пам'ять — у єдиному SO-DIMM модулі. Помилкова попередня здогадка про "4 GB припаяно" спростована даними BIOS.
2. **Другий слот вільний** — можна додати без заміни існуючого.
3. **Максимум 32 GB** — підтверджено і BIOS, і офіційним service manual HP, і користувачами форумів які встановлювали 2× 16 GB.
4. **Тип пам'яті**: DDR4 SO-DIMM 260-pin, JEDEC, 1.2V, CL22. Купувати DDR4-3200 (працюватиме на 2400 — це обмеження CPU, не пам'яті). Можна і DDR4-2400/2666, але різниця в ціні мізерна, тож беремо 3200 на майбутнє.
5. **Бонус від UMA**: у BIOS можна знизити iGPU framebuffer з 2 GB до 512 MB / 1 GB якщо ноутбук не використовується для ігор. Це звільнить ~1 GB для системи без жодних витрат.

## Варіанти апгрейду

> Ціни наведено орієнтовно. **Потрібно перевірити на реальному ринку перед покупкою** — попередні WebSearch-оцінки виявилися заниженими у 2.5–4 рази через анкер на "starting from" ціни маркетплейсів.

| Варіант | Що робити | RAM total | Швидкість пам'яті vs нинішня | LLM що відкривається | Ціна (потребує перевірки) |
|---|---|---|---|---|---|
| **0. Залишити** | Нічого | 8 GB (5.88 видимих) | 1.0× single-channel | Qwen 1.5B Q4 (тісно) | 0 |
| **A. Мінімум** | + 1× 8 GB у пустий слот | 16 GB | ~1.9× dual-channel | Qwen 3B комфортно, Qwen 7B впритул | низька |
| **B. Flex Mode** | + 1× 16 GB у пустий слот | 24 GB | ~1.7× (Flex 8+16) | Qwen 7B комфортно, Qwen 14B можливо | середня |
| **C. Симетричний матчений kit** | замінити на 2× 16 GB kit | 32 GB | ~1.95× full dual-channel | Qwen 14B комфортно | висока |

### Про AMD Flex Mode (важливо)

На Ryzen Zen+ контролер пам'яті підтримує **асиметричні конфігурації**:
- 8 GB + 16 GB: 16 GB працює в dual-channel + 8 GB у single-channel = 24 GB total
- Це **не** деградація відносно single-channel, це **покращення** на ~70%
- Програш vs повністю симетрична пара 16+16 — 5–10% у memory-bandwidth bound задачах

Для LLM-інференсу (memory-bandwidth bound на CPU) Flex Mode 8+16 дає ~95% продуктивності матченого 16+16. Тобто варіант B — раціональний компроміс ціна/якість, але потребує впевненості що "не всі планки однакові — це нормально".

### Про матчені kit'и

Парний kit (наприклад Kingston `KVR32S22D8K2/32`, Crucial `CT2K16G4SFRA32A`, Patriot `PSD432G3200SK`, GOODRAM `GR3200S464L22S/32GDC`) — два модулі однієї партії, перевірені виробником разом. Гарантовано працюють у dual-channel без сюрпризів. Шукати позначення `K2`, `kit`, `2x16` — це гарантує що це справжня пара.

## Рекомендований шлях ухвалення рішення

```
1. Поточний крок: запускаємо Qwen 1.5B на наявних 8 GB (без витрат)
   ↓
2. Тестуємо на реальних 50+ наказах
   ↓
3. Оцінюємо точність:
   - Класифікація типу наказу: ціль ≥85%
   - Витяг полів (ПІБ, дата, номер наказу): ціль ≥85%
   ↓
4а. Якщо точність прийнятна → зупиняємось, апгрейд не потрібен
4б. Якщо ні → дивимося реальні ціни в Україні і обираємо B або C
   ↓
5. Альтернатива до апгрейду цього ноута: купівля б/у ноута з 16 GB
   на борту (Ryzen 5/7 4xxx серії на OLX) — може бути вигіднішим
   ROI ніж апгрейд цього (CPU кратно потужніший + більше RAM відразу)
```

## Інструкція по самостійній заміні пам'яті

Складність: легка. Час: 15–30 хв. Ризик: мінімальний при дотриманні процедури.

### Що знадобиться

- Маленька хрестова викрутка PH00 або PH0
- Пластиковий медіатор / стара пластикова банківська картка (для відщіпання кліпсів)
- Антистатичний браслет — бажано, але не критично якщо торкнутися металевого корпусу перед роботою

### Покрокова процедура

1. **Підготовка**
   - Закрийте всі програми, вимкніть ноутбук повністю (не sleep, не hibernate).
   - Відключіть зарядний кабель.
   - Вийміть USB-флешки, миші, навушники — все периферійне.
   - Натисніть кнопку power і потримайте 10 секунд для розряду конденсаторів.

2. **Відкриття нижньої кришки**
   - Переверніть ноутбук на м'яку поверхню (рушник, тканина) екраном донизу.
   - Викрутіть видимі гвинти Phillips з нижньої кришки (зазвичай 8 штук).
   - **Перевірте під гумовими ніжками** — там часто заховано ще 2 гвинти. Гумки відклеюються нігтем або тонким лезом, потім приклеюються назад.
   - Усі гвинти складіть у магнітну тарілку або акуратно на стіл за схемою (вони можуть бути різної довжини — важливо повернути той самий гвинт у те саме місце).

3. **Зняття кришки**
   - Пластиковим медіатором або старою банківською карткою обходьте по периметру кришки і обережно відщіпайте кліпси.
   - **Не використовуйте металеву викрутку** — поламаєте пластикові кліпси.
   - Починайте з кута, рухайтесь повільно. Будуть чутні клацання — це нормально.
   - Кришка зніметься повністю.

4. **Заземлення**
   - Перед тим як торкатися компонентів — торкніться металевої частини шасі ноутбука рукою (наприклад порту USB зсередини). Це зрівняє статичний потенціал з ноутбуком.
   - У сухому опалюваному приміщенні взимку — додатково торкніться металевого радіатора або водопровідної труби перед роботою.

5. **Доступ до слоту пам'яті**
   - Знайдіть слоти пам'яті — зазвичай поруч з CPU під чорним пластиковим/металевим прикриттям-екраном (може й не бути).
   - У вас слот 1 (лівий) зайнятий 8 GB Hynix, слот 2 (правий) — пустий.
   - Якщо є екран над слотами — обережно зніміть.

6. **Встановлення нової планки** (для варіанту B — додавання у пустий слот)
   - Вийміть нову SO-DIMM з антистатичного пакету, тримайте за бічні краї.
   - **Не торкайтесь золотих контактів** і не торкайтесь чіпів пам'яті.
   - Вирівняйте виріз на контактах планки з виступом у слоті — є один правильний поворот, помилитись неможливо.
   - Вставте планку у слот **під кутом ~30°** — спочатку контакти заходять у слот.
   - Потім обережно притисніть планку донизу — бічні фіксатори клацнуть і утримують її.
   - Перевірте візуально: планка має лежати рівно, бічні фіксатори зачеплені у пази на торцях.

6б. **Якщо варіант C — заміна на матчений kit**
   - Спочатку **вийміть** стару Hynix: відведіть бічні фіксатори назовні, планка вистрибне під кутом, тоді витягніть її.
   - Покладіть стару планку в антистатичний пакет — буде як запасна або на продаж.
   - Встановіть обидві нові планки за процедурою з кроку 6.

7. **Збірка**
   - Поставте кришку на місце, починайте з протилежного від петель краю.
   - Притисніть по периметру — кліпси клацнуть.
   - Закрутіть гвинти **на тому самому місці звідки виймали** (різна довжина).
   - Поверніть гумові ніжки на місце.

8. **Перший запуск**
   - Підключіть зарядку, увімкніть ноутбук.
   - Перший POST може тривати 30–60 секунд (BIOS тренує таймінги пам'яті) — це нормально, не перезавантажуйте насильно.
   - Після завантаження Windows перевірте розпізнання:
     ```powershell
     Get-CimInstance Win32_PhysicalMemory | Select-Object DeviceLocator, Capacity, Speed
     ```
   - Має показати обидві планки.

9. **Опційно: перевірка стабільності**
   - Запустіть [MemTest86](https://www.memtest86.com) з USB-флешки на 1–2 проходи. Якщо нуль помилок — пам'ять справна.
   - На щодень не обов'язково, але корисно перед серйозним використанням.

### Що може піти не так

| Симптом | Що робити |
|---|---|
| Ноут не вмикається після збірки | Розкрити, перевірити що планка повністю клацнула у фіксатори |
| BIOS показує менше пам'яті ніж треба | Перевернути планку (правильний виріз), повторно вставити |
| Багатократні перезавантаження при POST | BIOS тренує таймінги — почекати 1–2 хв |
| Windows синіє після завантаження | Несумісність планки. Якщо нова — повернути в магазин по гарантії |
| Один з модулів дає MemTest помилки | Брак планки. Замінити по гарантії |

## Альтернатива апгрейду: віддалений Ollama

Якщо у вас є інша машина (домашній ПК, робочий комп) з 16+ GB RAM:

1. Ставите на неї **Ollama** (https://ollama.ai), завантажуєте Qwen2.5-7B-Instruct.
2. Запускаєте Ollama як сервер: `OLLAMA_HOST=0.0.0.0:11434 ollama serve`.
3. Відкриваєте порт 11434 у firewall локальної мережі.
4. У Shozilla на ноуті в settings вмикаєте "Remote Ollama", вказуєте `http://192.168.x.x:11434`.
5. Дані не виходять з вашої локалки, ноут не парить ресурси, якість 7B/14B без апгрейду.

Цей шлях передбачений у баклозі (`AI-баклог: Підтримка віддаленого Ollama`).

## Невирішені питання

- [ ] Реальні роздрібні ціни на DDR4 SO-DIMM в Україні станом на травень 2026 — потрібно перевірити на Rozetka / Brain / Hotline безпосередньо. Попередні WebSearch-оцінки в 2.5–4 рази нижчі за реальність.
- [ ] Якість Qwen 1.5B на реальних військових наказах — буде відомо після виконання AI-1 і тестування на 50+ документах.
- [ ] Чи підтримує BIOS F.52 ECC перевірку non-ECC планок коректно при різних виробниках — не критично, але теоретично можливі edge cases на дешевих модулях.
